# walkthebeat docs

beat answers questions about your Linux hosts. A sensor on each host runs questions it is sent, if one of your
org's members signed them, and sends the answers to the beat service. On your laptop, the `beat` CLI and your
agent (Claude, through beat's MCP server) ask the questions and read the answers.

- [Getting started](getting-started.md): from sign-up to a first question, on one host or many.
- [The sensor](sensor.md): what it does on a host, what it sends, and how to remove it.
